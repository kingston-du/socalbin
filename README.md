# SoCalBin

The website for SoCalBin, the trash can cleaning business I co-founded with Eliseo in Rancho Cucamonga. We got our first 20+ customers by going door to door, and this page is where they see the pricing, read how it works, and text us to book. Live at [kingston-du.github.io/socalbin](https://kingston-du.github.io/socalbin/).

## Stack

React, TypeScript, TanStack Start, Vite, and Tailwind CSS. I made it in Lovable. It's prerendered to static HTML and deployed to GitHub Pages by a GitHub Action.

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:8080/socalbin/.
